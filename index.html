How do I know?

The first tag inside this page's <head> is a Content-Security-Policy, a rule your browser enforces on the page. It sets connect-src 'none' (no fetch, XMLHttpRequest, WebSocket or beacon connections), form-action 'none' (no form posts), img-src data: (no remote images) and default-src 'none' (no other network loads); the only thing it may load from the internet is the Tailwind styling script from cdn.tailwindcss.com. Your files are read into memory with the browser's File API, are never written to browser storage, and are gone when you refresh or click "Clear all data". To check for yourself, open your browser's developer tools (F12), watch the Network tab while you load a file and see that nothing is sent, or turn off Wi-Fi after the page opens and see that everything keeps working.

Summary

The GFI worksheet contains patient data (Rx numbers, dates of service). The de-identified summary has counts and dollars only and is the only export safe to share before a BAA. Tip: in Excel, open CSVs with Data → From Text/CSV and set ID columns to Text so leading zeros and long claim numbers are kept.

Ledger: provider adjustments (PLB)

WO = overpayment recovery (clawback), FB = forwarding balance. X12 convention: a positive PLB amount is taken out of the payment; a negative amount is added to it.
